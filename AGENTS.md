# Notification ticker

This folder is an Omarchy shell plugin, not a studio web app. The theme, language, and browser rules in `../AGENTS.md` do not apply.

`Service.qml`, `NotificationLogic.js`, and `components/NotificationCard.qml` come from Omarchy's notification daemon. Read `NOTICE.md` and `README.md` before editing them. The ticker itself is `components/TickerWindow.qml` plus the ticker settings in the daemon.
